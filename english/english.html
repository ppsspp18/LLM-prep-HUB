How to Use English / VARC Hub

  1. Select your Practice Mode (e.g. Reading Comprehension, Para Jumbles, Tech Job Communication) and target level.
  2. Click 📋 Copy Practice Prompt and paste it into any LLM (ChatGPT, Claude, Gemini).
  3. Paste the returned JSON into Paste Practice JSON and click Generate Practice.
  4. Read the passage (for RC) and select your answers for each question.
  5. Click Submit Test to view your score and detailed answer keys.
  6. Click 📋 Copy Concept & Knowledge Gap Prompt — the LLM will give you a single cohesive response deeply explaining the reading, reasoning, and grammar concepts you missed.
