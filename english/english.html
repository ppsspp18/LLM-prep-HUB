How to Use English Learner

  1. Describe what sentences you want in What to Generate (e.g. daily routine, restaurant, travel).
  2. Click 📋 Copy Hinglish Prompt and paste it into any LLM (ChatGPT, Claude, Gemini) to generate Hinglish sentences.
  3. Paste the returned JSON into the Paste Hinglish Sentences JSON box and click Generate Sentences.
  4. Type the correct English translation for each Hinglish sentence.
  5. Click 📋 Copy Response Prompt, paste it into the LLM to get mistakes & improvements.
  6. Paste the returned feedback JSON and click Show Feedback to see your mistakes and how to improve.
