How to Use Interview Mode

  1. Configure your target Role, Core Focus, and difficulty level.
  2. Click 📋 Copy Prompt and paste it into an LLM (ChatGPT, Claude, Gemini) to generate open-ended questions.
  3. Paste the returned JSON into Paste Interview Questions JSON and click Generate.
  4. Write your answers to each technical interview question.
  5. Click 📋 Copy Comprehensive Feedback Prompt — this prompts the LLM for a single unified response that deeply explains forgotten concepts and architectural principles.
  6. Paste the AI feedback into the box below to view it nicely formatted.
